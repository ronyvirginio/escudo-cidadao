# 🛡️ Escudo Digital Cidadão

O **Escudo Digital Cidadão** é uma aplicação web desenvolvida como projeto de extensão universitária no curso de Ciência da Computação. Unindo conceitos de investigação digital e segurança da informação, o projeto tem como objetivo educar a população sobre ameaças cibernéticas e oferecer ferramentas práticas para a prevenção de fraudes digitais.

Você pode acessar o projeto na internet através do site: https://escudocidadao.com.br/

## ⚙️ Funcionalidades

* **Educação Interativa:** Quizzes de segurança cibernética para testar e aprimorar o conhecimento do usuário sobre práticas seguras na internet.
* **Verificação de Domínios (WHOIS):** Ferramenta integrada para consultar o tempo que o site está rodando, ajudando a identificar páginas fraudulentas de phishing.
* **Como registrar ocorrência:** Dicas úteis se você caiu em um golpe.

## 💻 Tecnologias Utilizadas

O projeto foi construído com foco em eficiência, utilizando um ecossistema Python robusto para o backend e ferramentas modernas para o deploy.

* **Backend:** Python 3, Flask
* **Integrações de Segurança:** Bibliotecas de consulta WHOIS
* **Frontend:** HTML5, CSS3, JavaScript (Templates Jinja2)
* **Hospedagem / Deploy:** Render
* **Controle de Versão:** Git & GitHub

## 🔍 Contexto do Projeto

Este projeto nasceu da necessidade de traduzir o conhecimento técnico de inteligência cibernética e investigação para uma linguagem acessível ao cidadão comum. Ao transformar técnicas de verificação (como análise de cabeçalhos e consultas de registro) em uma interface web simples, o sistema atua como uma primeira linha de defesa contra a engenharia social e os cibercrimes cotidianos.
